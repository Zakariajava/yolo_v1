YOLOv1 from Scratch on COCO 2017
Zakaria Abouhammadi · Universitat de València · May 2026
Problem

Object detection

Step 1
Classify — what objects are in the image?
e.g. person, motorcycle
Step 2
Localize — where is each one?
a bounding box (x, y, w, h) for every instance
Output is variable-length and structured — different from classification.
Background

Two ways to do it

Two-stage
R-CNN, Fast R-CNN, Faster R-CNN
  • Propose candidate regions
    selective search · RPN
  • Classify each region separately
  • High accuracy · slow
Single-stage
YOLO, SSD, RetinaNet
  • One forward pass
  • Dense regression on a fixed grid
  • Real-time capable
YOLO  =  You Only Look Once
Method · 1 of 3

Divide and conquer

Goal: predict one box per object, per class.
Divide the image into an S × S grid.
Paper: S = 7. Here S = 3 for clarity — 9 cells.
Each object has exactly one midpoint
→ falls in exactly one cell.
That cell is responsible for predicting
that object. By design: one object per cell.
Limitation: if two objects share a cell, only one is kept.
Method · 2 of 3

How each cell predicts a box

(x, y) — midpoint relative to the cell
always in [0, 1]
(w, h) — width / height relative to the image
can be > 1 if the object spans multiple cells
label = [ 0.95, 0.55, 0.5, 1.5 ]
x, y · w, h — that's it for one box.
Method · 3 of 3

What the network outputs per cell

pred_cell = [ c1, c2, …, c80 │ p1, x, y, w, h │ p2, x, y, w, h ]
80 class probabilities
One per COCO class, summing softmax-like across the cell.
Box 1 · 5 numbers
objectness p₁ + coords x, y, w, h
Box 2 · 5 numbers
a second candidate, same layout
Total per image  =  7 × 7 × 90 = 4,410  numbers
Note: class probs are per-cell, not per-box.
B boxes in a cell share the class prediction.

Metric · 1 of 2

Intersection over Union (IoU)

$$\mathrm{IoU}(A, B) \;=\; \dfrac{|A \cap B|}{|A \cup B|}$$
  • Values in [0, 1]
  • Used in the loss: which box is responsible?
  • Used in evaluation: TP if IoU ≥ 0.5
Method · loss

Loss function

$$\lambda_{\text{coord}} \sum_{i=0}^{S^2}\sum_{j=0}^{B} \mathbb{1}_{ij}^{\text{obj}} \big[(x_i - \hat{x}_i)^2 + (y_i - \hat{y}_i)^2\big]$$
Center coords (x, y) — responsible cell only · weighted by λ_coord = 5
$$+\;\lambda_{\text{coord}} \sum_{i=0}^{S^2}\sum_{j=0}^{B} \mathbb{1}_{ij}^{\text{obj}} \big[(\sqrt{w_i} - \sqrt{\hat{w}_i})^2 + (\sqrt{h_i} - \sqrt{\hat{h}_i})^2\big]$$
Box size √w, √h — square root makes small-box errors matter more
$$+\;\sum_{i=0}^{S^2}\sum_{j=0}^{B} \mathbb{1}_{ij}^{\text{obj}} (C_i - \hat{C}_i)^2$$
Confidence when an object is present
$$+\;\lambda_{\text{noobj}} \sum_{i=0}^{S^2}\sum_{j=0}^{B} \mathbb{1}_{ij}^{\text{noobj}} (C_i - \hat{C}_i)^2$$
Confidence when no object — weighted by λ_noobj = 0.5 (most cells are empty)
$$+\;\sum_{i=0}^{S^2} \mathbb{1}_{i}^{\text{obj}} \sum_{c \in \text{classes}} (p_i(c) - \hat{p}_i(c))^2$$
Class probability — at object-containing cells only
Only the box with highest IoU vs ground truth — the responsible box — contributes to terms 1–3. The other one contributes only to term 4.
Inference

Non-Max Suppression

Predictions are noisy — many boxes for the same object.
Discard low-confidence — threshold ≈ 0.4
Keep the max — and compare its IoU vs the rest.
Drop duplicates — any box with IoU > 0.5 vs the kept one.
Repeat per class.
Metric · 2 of 2

How do we measure detection quality?

Detection produces guesses with confidence scores.
Like a fisherman casting a net — what's in it?
Scenario A · The careful fisherman 2 fish, nothing else
Precision = 2 / 2 = 100%   ·   Recall = 2 / 10 = 20%
Precise, but missed 8 fish.
Scenario B · The greedy fisherman 10 fish + 10 bottles, branches
Precision = 10 / 20 = 50%   ·   Recall = 10 / 10 = 100%
Caught them all — but lots of junk.
Plot precision (y) vs recall (x) over all confidence thresholds → PR curve.
AP = area under PR curve, per class.
mAP = mean of AP across the 80 classes.
Implementation

Training infrastructure

Dataset & Model
  • Dataset: COCO 2017 · 80 classes · 123K images
  • Split: 90 / 5 / 5 (train / val / test) · seed = 42
  • Backbone: pretrained ResNet18 (ImageNet)
  • Total: ~248M params
Training
  • Mixed precision FP16 forward · FP32 master weights
  • DDP scaffolding · in practice 1 × H100 / H200
  • SGD · momentum 0.9 · wd 5e-4
  • 60 epochs · peak LR 1e-4 · cosine schedule
  • ~95 min / run on an H200

Bug forensics · 2 of 2

Audit found two independent bugs

Bug 1 Loss indexed for the wrong dataset
  • Loss code wrote OBJ_IDX = 20 · the VOC layout
  • Real layout on COCO: OBJ_IDX = 80
  • Of 1,062 object-containing cells in 200 sample images, the exists_box mask fired on only 3 cells —
    the elephants, whose class index happened to land where the confidence channel should be.
→ The model was gradient-blind to the bounding-box channels.
The loss was "a loss" — just not the YOLO loss.
Bug 2 Decoder divided w, h by S = 7
  • Decoder treated w, h as cell-relative (like x, y)
  • But w, h were stored image-relative all along
  • Even a perfectly trained model would emit boxes 7× too small
→ Maximum achievable IoU ≈ 0.02 — well below the 0.5 threshold for a TP.
Each bug alone is sufficient to produce mAP = 0. Both were invisible to the unit tests, which checked shapes but not invariants.
The lesson

If you take one thing from this talk

“
A converging loss is not evidence
that the model is learning
what the loss is supposed to measure.
”
When detection gives zero, ask
is the loss the loss?
— before tuning hyperparameters.
A round-trip test (encode → decode → assert) would have caught both bugs in one line, before the first epoch.
